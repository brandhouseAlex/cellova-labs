# Cellova Brand Notes

These notes summarize the provided **Cellova Labs Visual Brand Guidelines** and serve as the implementation reference for rebranding the copied Next.js storefront while preserving the original Cellova site architecture.

## Core palette

| Token | Hex | Intended use |
| --- | --- | --- |
| Ink | `#12141C` | Primary dark text, footer, navigation, deep surfaces |
| Paper | `#F3F4F1` | Primary light background and labels |
| Slate | `#8B93A7` | Metadata, dividers, borders, muted UI |
| Indigo | `#2D3452` | Headings, panels, structural emphasis |
| Spark | `#F2A63C` | Logo, CTAs, accent moments |

The guidelines describe the balance as approximately **60% Paper/white**, **25% Ink + Indigo**, **10% Slate**, and **5% Spark**. Spark should not be used as small text on Paper.

## Typography

| Role | Typeface | Use |
| --- | --- | --- |
| Display | Sora 700 | H1-H3, hero statements, product names |
| Interface | Inter 400-700 | Body copy, navigation, buttons, UI labels |
| Technical | IBM Plex Mono 500 | Lot numbers, SKU, COA/technical details |

Representative approved copy includes **“Precision You Can Verify.”** for the display treatment.

## Logo system

Approved wordmark treatments shown in the guidelines are:

| Treatment | Context |
| --- | --- |
| Primary on Paper/white | Standard light backgrounds |
| Reversed on Indigo or Ink | Dark-panel usage |
| One-color Ink | Monochrome light-background usage |
| One-color Paper | Monochrome dark-background usage |

The guidelines require preserving proportions, tracking, clear space, and the relationship between **Cellova** and **LABS**. Minimum width shown is **180 px digital / 1.5 in print**.

## Homepage art direction

The hero direction emphasizes **clarity over hype**, pairing the Cellova mark with a structured research-product presentation, high contrast, restrained premium layout, and Spark-driven CTA emphasis over Paper/Ink/Indigo surfaces.

## Implementation rule

When rebranding the copied original Next.js storefront, preserve the original working layout and architecture, but replace Cellova-branded visual tokens with the Cellova palette, typography, logo treatments, and CTA hierarchy documented above.
