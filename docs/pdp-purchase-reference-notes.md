# PDP Purchase-Area Reference Notes

These notes preserve the exact visible requirements from the purchase-panel mockup included in the user message. The restricted attachment was not reopened.

| Region | Visible reference requirement applied to the PDP |
| --- | --- |
| Purchase shell | A single pale blue, softly rounded panel begins immediately below the dynamic price. |
| Primary row | The quantity stepper is a white bordered control on the left; a large Spark/amber **ADD TO CART** button fills the right side. |
| Quantity treatment | Minus, current quantity, and plus are horizontally aligned and separated by thin vertical rules. |
| Fulfillment area | A thin horizontal rule follows the primary row, then five evenly spaced rows with an Indigo icon, bold Indigo label, and muted slate detail. |
| Exact visible rows | **Free standard shipping** / “on orders over $150”; **Next day shipping** / “Mon–Thu before 12 p.m. EST”; **UPS** / “2–5 business days; Overnight options available at checkout.”; **Secure checkout** / “Credit card processing available.”; **Expert support** / “Have questions? We’re here to help.” |
| Responsive intent | The purchase shell remains a single panel; the action row stacks at smaller widths while the fulfillment rows retain the icon, label, and detail hierarchy. |

The implementation retains provider values for selected variant, price, availability, quantity, and cart identifiers. Only the surrounding purchase presentation and mockup-supplied fulfillment copy are static.
